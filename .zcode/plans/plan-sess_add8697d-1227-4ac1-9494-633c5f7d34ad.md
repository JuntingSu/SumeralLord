## 功能：房主为势力指定 AI 难度（AI 接管下）

**需求**：开启 AI 接管后，房主可为单个势力指定 AI 难度（1/2/3/255）；指定后该势力为 AI 专属、玩家不可选取。已确认的两个边界：① 对已有玩家的势力指定 → 拒绝（`FORCE_OCCUPIED`，提示先移出，不自动移人）；② 关闭 aiTakeover → 清空全部指定。

### 1. 数据模型与协议（shared）
- `packages/shared/src/types.ts`：`RoomForce` 增加 `aiLevel: number | null`（null=未指定，开局按地图默认 computer；指定后 AI 专属不可选）。
- `packages/shared/src/constants.ts`：在 `AI_LEVEL` 旁增加难度中文标签 `AI_LEVEL_LABEL = {1:'简单',2:'普通',3:'困难',255:'休闲'}`（前端显示用）。
- `packages/shared/src/game/types.ts`：`SeatAssignment` 增加 `computer?: number`（开局难度覆盖；缺省用地图 player_list[].computer）。
- `packages/shared/src/protocol.ts`：新增 `ForceAiBodySchema`（`{ seat: 0..127, aiLevel: 1|2|3|255|null }`）与 `ForceAiBody` 类型。

### 2. 后端房间 manager（backend/src/room/manager.ts）
- `toRoomForces`：forces 初始 `aiLevel: null`（换图 `changeMap` 自动重置为 null）。
- 新方法 `assignForceAiLevel(hostUserId, roomId, seat, aiLevel)`：
  - 房主校验（`NOT_HOST`）、对局中/结束拒绝（`IN_GAME`/`GAME_OVER`）、势力存在校验；
  - `room.aiTakeover` 未开启 → `AI_TAKEOVER_OFF`；
  - 该势力 `playerId !== null` → `FORCE_OCCUPIED`（拒绝）；
  - `aiLevel` ∈ {1,2,3,255} 或 null（null=清除）；
  - 设 `force.aiLevel`，广播 `ROOM_UPDATE`（携带 aiLevel，走现有全量房间广播路径）。
- `selectForce`：在 `FORCE_TAKEN` 判定前插入 `force.aiLevel !== null → FORCE_AI_LOCKED`（AI 专属不可选；seat=-1 取消分支不受影响）。
- `updateSettings`：patch 中 `aiTakeover === false`（明确关闭）→ 清除全部 forces 的 `aiLevel` 后照常广播 `ROOM_UPDATE`。

### 3. 后端 API（backend/src/api/rooms.ts）
- 错误码→HTTP 映射补充：`FORCE_AI_LOCKED`/`FORCE_OCCUPIED`/`AI_TAKEOVER_OFF`。
- 新路由 `POST /api/rooms/:id/force-ai`（body=ForceAiBody）→ `assignForceAiLevel` → 返回全量 RoomData（与 `/force-remove` 同模式）。
- `start` 的 isAI 判定改为按势力：`isAI = f.aiLevel !== null || (roomData.aiTakeover && f.playerId === null)`；`seatAssignments` 中 `f.aiLevel !== null` 时带 `computer: f.aiLevel`。`randomSpawn` 洗牌（`shuffleAssignments` 用展开保留 computer）与 `usePersonalSkin` 逻辑不受影响。

### 4. 开局难度覆盖链路
- `packages/shared/src/game/reducer.ts` `initState`：`computer: assign?.computer ?? p.computer`（指定难度覆盖地图默认，流入 `ForceState.computer` → 难度1 策略/休闲跳过均按此生效）。GAME_START 持久化含 computer，回放/重连一致。

### 5. 前端
- `frontend/src/api/room.ts`：新增 `setForceAiLevel(roomId, seat, aiLevel: number | null)` → POST `/force-ai`。
- `frontend/src/pages/Room.tsx` 势力列表：
  - 扮演玩家列：`f.aiLevel !== null` 时显示 AI 难度徽标（如「AI·简单」），否则照旧（玩家名或 '—'）。
  - 无主势力行：`isHost && room.aiTakeover` 时在操作列显示 AI 难度下拉（未指定/休闲/简单/普通/困难；已指定可改可清除）；`f.aiLevel !== null` 时玩家侧显示「AI 专属」而非「选择」按钮（不可选取）。
  - 已占势力不显示该控件（后端拒绝，符合"先移出"决策）。

### 6. 测试
- backend rooms.test.ts：房主指定/清除成功（ROOM_UPDATE 携带 aiLevel）；非房主 403；aiTakeover 未开 → `AI_TAKEOVER_OFF`；已占势力 → `FORCE_OCCUPIED`；AI 锁定势力被玩家 select-force → 409 `FORCE_AI_LOCKED`；关闭 aiTakeover 清空全部指定。
- backend game.test.ts：aiTakeover + 指定难度开局 → GAME_START.seatAssignments 中该 seat `isAI:true` 且 `computer=指定值`；未指定无主势力 computer 缺省。
- shared tests：reducer initState 带 `computer` 覆盖 → `ForceState.computer` 用覆盖值；不带 → 地图默认。
- 全量 lint / typecheck（前后端）/ 测试 / 前端构建通过。

### 7. 边界
- 换图重置 forces → aiLevel 清空；解散/对局中不可指定；难度 255=休闲（跳过）；指定后玩家不可选由前后端双重拦截。
