## 目标
在 `mapeditor` 分支上开发一个**独立地图编辑器网页**（纯静态、无构建、无依赖），针对当前项目「本地数字领主」的地图格式（JSON 文件）。先产出技术文档，再写代码。

## 第一步：分支与技术文档（先文档后代码）
1. `git checkout -b mapeditor`（基于 master）
2. 新建 `mapeditor/技术文档.md`，内容包括：
   - 参考项目 mapeditor-release 的功能清单与架构分析
   - 当前项目地图数据结构完整规范（TERRAIN 0/1/3/4/5、TILE_OWNER 128/0/255+seat、battlefield 扁平三元组、index 0 左下、player_list、AI 难度 1/2/3/255、时间设置、校验规则 catalog.isValid）
   - 参考项目与当前项目地图结构的差异对照表（地形编码、坐标原点、难度取值、野生/阻挡兵力规则、I/O 方式）
   - 编辑器设计规格（坐标/渲染/拾取几何、编辑规则联动、保存导出工作流、后端保存 API 设计）

## 第二步：后端保存 API（小改动，支撑「保存到 maps-uncensored」）
- `backend/src/maps/catalog.ts`：把私有 `isValid` 提取为可复用导出函数，供目录加载与保存接口共用
- `backend/src/api/maps.ts`：新增 `POST /api/maps`——校验地图 JSON → 写入 `backend/static/maps-uncensored/{id}.json`（目录不存在则创建；id 严格白名单 `^[a-zA-Z0-9_-]+$` 防路径穿越）
- `backend/src/app.ts` + `backend/src/declarations.d.ts`：计算并装饰 `mapsUncensoredDir`
- 说明：该接口与现有 maps 公开接口一致不设鉴权（后端默认仅绑定 127.0.0.1，本地开发工具），文档中注明

## 第三步：编辑器前端（repo 根目录 `mapeditor/`）
文件布局：
- `mapeditor/index.html` + `mapeditor/css/style.css`：单页布局（顶栏文件操作、左栏画笔/工具、中央 Canvas、右侧势力与地图信息面板）
- `mapeditor/js/constants.js`：TERRAIN / TILE_OWNER / AI_LEVEL / 标签 / 颜色（对齐当前项目）
- `mapeditor/js/mapdata.js`：新建默认图、四边扩缩行列（重排扁平数组）、删除势力级联清理战场、数据规范化
- `mapeditor/js/render.js`：Canvas 六边形渲染（对齐 HexMapPreview 几何：尖顶、奇数行右移半格、index 0 左下、Y 翻转、HiDPI）、平移/缩放、像素→格子拾取、悬停 tooltip
- `mapeditor/js/editor.js`：编辑状态机——画笔（地形/归属/兵力/出生点）、笔刷模式（全部/仅地形/仅兵力）、撤销/重做（快照栈）、Struct 区域复制/粘贴（透明格 255 跳过）
- `mapeditor/js/io.js`：JSON 解析（剥离 `//` 注释）、导出 JSON 下载（文件名=id）、保存到服务器（服务器地址可配置，默认 `http://127.0.0.1:3000`，POST /api/maps → maps-uncensored）、从服务器加载官方地图列表
- `mapeditor/js/players.js`：势力表格（增/删/重排、编辑 name/team/computer/seat/flag、旗帜色块预览——黄金角 HSL 映射）
- `mapeditor/js/validate.js`：结构校验（对齐 catalog.isValid）+ 软校验（每势力恰一座出生点、全图无 terrain=2、battlefield 长度=row×column）
- `mapeditor/js/generator.js`：随机地图生成器（移植参考 generator.py，地形编码映射到当前项目 0/1/3/4/5）
- `mapeditor/js/main.js`：装配启动
- `mapeditor/samples/`：官方 3 张地图副本作为离线模板

## 功能清单
- 文件：新建（行/列/势力数）/ 打开（文件选择+拖拽）/ 导出 JSON / 保存到服务器(maps-uncensored) / 从服务器加载官方图
- 地图信息：title/description/author/tags/timestamp/random_spawn/cylindrical_map/fog_mode/时间设置/id(文件名)
- 势力编辑：增删/重排/改属性/旗帜色预览/删除级联清理
- 绘制：地形画笔（平原/据点/海洋/山地/虚空）、归属画笔（无主/野生/阻挡/各玩家）、兵力画笔、出生点快捷工具（据点+归属seat+兵力）
- 规则联动：山地/虚空不可驻兵（强制无主+兵力0）；无主强制兵力0；野生/阻挡可有兵力（与当前游戏 initState 一致）
- 高级：撤销/重做、Struct 区域复制/粘贴、随机地图生成器、校验面板
