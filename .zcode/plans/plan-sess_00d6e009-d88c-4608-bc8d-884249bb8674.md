## POV 分支改动计划

新开 `pov` 分支,实现 8 项局内改动。全部改动为前端本地逻辑(游戏状态前端本地权威、各端演算同一事件链,因此系统通知由前端本地生成即可,无需后端改动)。

### 0. 分支
- `git checkout -b pov`(从当前 master 状态切出,未提交的改动一并带过去)

### 1. 聊天条目支持系统通知 — `frontend/src/stores/room.ts`
- `ChatEntry` 增加可选字段 `kind?: 'system'`(房间聊天不受影响)。

### 2. 游戏 store 生成系统通知 — `frontend/src/stores/game.ts`
- 新增类型 `SystemNotice`:
  ```ts
  type SystemNotice =
    | { kind: 'turnStart'; seat: number }
    | { kind: 'forceCleared'; seat: number; killerSeat: number | null; reason: 'no_stronghold' | 'surrender' | 'timeout' }
    | { kind: 'killStreak'; seat: number; kills: number };
  ```
- 新增纯函数 `collectSystemNotices(chain, fromSeat, prevKillCounts): { notices, killCounts }`(便于单测):
  - 遍历链中 `FORCE_CLEAR`:`reason === 'no_stronghold'` 时击杀者=`fromSeat`(意图发起者),计入 `killCounts[killerSeat]`,击杀数 ≥ 3 时追加 `killStreak` 通知(**每次击杀都发**,按用户确认);`surrender`/`timeout` 无击杀者(`killerSeat=null`)。
  - 链中 `END_TURN` 且 `toSeat !== fromSeat` → 追加 `turnStart` 通知(第一回合没有 END_TURN,由 startGame 单独补)。
- store 新增状态:`systemNotices: SystemNotice[]`、`killCounts: Record<number, number>`;新增动作 `drainSystemNotices()`(仿 phaseAnnouncements 原子取出)、`pushSystemChat(text)`(追加 `{ from:0, username:'', text, ts:Date.now(), kind:'system' }` 到 chat,slice(-200))。
- `applyStreamMessage` 中,`replay=false` 时用 `collectSystemNotices` 收集通知写入 `systemNotices` 与 `killCounts`(重连重放不触发,与阶段提示一致)。
- `startGame` 中,开局首回合 `init.state.currentSeat > 0` 时补一条 `turnStart` 通知。
- `reset()` 清空 `systemNotices`、`killCounts`。

### 3. 局内主页面 — `frontend/src/pages/Game.tsx`
- **缩略侧边栏(需求1、3)**:每势力行内
  - 势力名后加绿色 `（我）`(`isMine = f.seat === mySeat`,仿详细模式 `text-emerald-400`);
  - 点数后加粉色 `(+N)`(`N`=该势力连兵数量,与详细模式同源计算 `board.tiles.filter(...isLinked)`);
  - 已清除势力显示 `已清除`(替代 points,与详细模式一致);容器宽度 `w-28` → `w-32` 容纳新增内容。
- **结束行动/结束加点按钮闪烁(需求2)**:新增 `lowActionTime = isMyActionTurn && (timer.stepTimeRemain < 10 || timer.gameTimeRemain < 10)`,为真时按钮加 `low-time-blink` class(1s 周期闪烁;计时器每秒 tick 自动刷新条件)。
- **系统通知消费(需求5、6、7)**:useEffect 订阅 `systemNotices`,drain 后按类型用 `room` 玩家用户名 + `board.forces` 势力名格式化成文本,`pushSystemChat` 写入聊天:
  - turnStart:`现在是[势力名（玩家名）]的回合`(AI/无玩家时省略 `（玩家名）`);
  - forceCleared:`刚刚[被杀方]被[击杀方]击杀了。` / `刚刚[被杀方]已投降。` / `刚刚[被杀方]已超时。`(按 reason;投降/超时也触发,按用户确认);
  - killStreak:`[势力名（玩家名）]正在大杀四方！`。
- **击杀飘字(需求4)**:本地 state `killFloats: { id, text }[]`;forceCleared 通知到达时追加 `${势力名}已被击败`,2s 后移除。渲染为 `fixed` 屏幕下部(`bottom-[30%]`,居中)白色黑描边字(`textShadow` 多方向描边),应用 `float-up-kill` CSS 动画上浮淡出。
