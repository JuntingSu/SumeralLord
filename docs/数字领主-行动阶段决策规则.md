# 数字领主·AI 行动阶段决策规则（v1.3）

> **用途**：AI 在行动阶段的决策挑选方法设计依据，与《数字领主战斗规则-v2》配套。战斗结算一律以战斗规则为准，本文件只规定**行为挑选与搜索流程**。
> **状态**：草稿。防守行为（§2）为占位，实现留空待定。
> **版本**：v1.5（2026-09-20）。

---

## 1. 行动阶段三段式结构

一个行动阶段按 **前置行为 → 基础行为 → 防守行为** 依次展开：

```
┌────────────────────────────────────────────────────────┐
│ 行动阶段                                                │
│                                                        │
│ ① 前置行为段   进攻据点（判定一次，见 §3）              │
│      ↓ 结束局面 = 根原点                                │
│ ② 基础行为段   5 种基础行为搜索（见 §4~§6）             │
│      ↓ 输出 3 条候选执行方案（含前置链）                 │
│ ③ 防守行为段   对每条候选路径下海防守（见 §2.1）        │
└────────────────────────────────────────────────────────┘
```

## 2. 行为分类与术语

| 术语 | 定义 |
|---|---|
| **前置行为** | 进攻据点。行动阶段**开始时判定一次**；执行后无"上一个行为" |
| **基础行为** | 5 种：铺场 / 就近进攻 / 远海进攻 / 自杀 / 兑换。构成搜索主体 |
| **防守行为** | 独立行为，位于基础行为段**之后**（第三段）。**不参与 5 基础行为的自身逻辑**（规则1 锁兵选择、原点枚举、top-4 备选链均不含防守）。对基础行为段输出的**每条候选路径分别执行**，实现见 §2.1 |
| **原点（Origin）** | 无"上一个行为"约束的局面，可自由选择任意兵的任何合法基础行为 |
| **行为链（Chain）** | 从某原点出发按规则1/2推进的完整行为序列（含自杀消耗战/兑换分支的延续），终止于规则2 或叶子 |
| **剪枝 E_ape** | 链终止时对终止局面调用 E_ape，作为该链在其起点原点处的打分，仅用于挑选备选链 |
| **方案 E_ape** | 基础行为段叶子原点的 E_ape，代表从根到该叶子的完整执行方案在**基础行为段**的得分 |

### 2.1 防守行为（v1.5 实现）

- **位置**：基础行为段之后（第三段），独立于 5 基础行为之外；对基础行为段输出的**每条候选路径分别执行**。
- **流程**（对某条候选路径的实施后局面 F）：
  1. **取基线**：E_base = E_ape(F)——**直接复用基础行为段对该路径算出的方案 E_ape**（防守行为在基础行为之后，无需重算当前局面 E_ape）。
  2. **枚举下海**：若 F 中我方仍存在**具有移动力**的兵，对每个这样的兵尝试"下海"：移动到距离 1 的**空海洋地块**，下海后不再移动（单意图 `MOVE`，一步入海即止）。
  3. **批准**：对每个兵的下海后局面分别计算 E_ape；**批准所有使 E_ape 相对基线 E_base 增加的下海行为**（各兵独立模拟、独立判定）。
  4. **成链**：被批准的下海行为形成意图列表；**若意图间冲突（目标地块相同），冲突意图从列表中排除**。
  5. **规则4（2026-09-20 新增）**：若 F 中存在我方**1 兵力断兵**（有移动力且未被基础行为/下海使用），命令其**向靠近敌方据点的方向移动一步**：目标 = 相邻空可走格中使"到最近敌方据点的 hex 距离"**严格减小**者，取移动后距离最小者；**多个相同距离位置随机走一步**（随机源 = 局面哈希做种子，同局面同结果）。规则4 意图与下海批准合并做目标格冲突排除。
  6. **提交**：该候选路径的**整体行动方案 = 前置链（若成立）+ 基础行为意图序列 + 防守意图列表**。3 条候选路径各自附上防守意图后，作为最终输出。
- **下海结算参考**（战斗规则 §8.1.1 / §8.2.1）：
  - 连兵下海 → 海洋格生成断兵，总兵力 −2（移动复制 −1、连→断转化 −1），原格留 1 连兵；生成兵力为 0 则海洋无兵；
  - 断兵下海 → 整体搬迁（兵力 −1），原兵删除；
  - 兵力 1 断兵下海后失去移动力；下海不触发失活（海洋无失活属性）；
  - 目标海洋格必须为空（有兵则该移动无效/转进攻，不作为下海候选）。

## 3. 前置行为：进攻据点

- **时机**：行动阶段开始时判定**一次**；不满足则整个行动阶段不再尝试（基础行为搜索中不判前置）。
- **成立条件**：存在敌方据点 P，其周围（距离 1）有我方兵集合 S（|S| ≥ 1，均能对 P 发起合法进攻：有移动力、非同队），满足 Σ 进攻力(s) **>** P 上防守兵兵力。
- **意图链**：S 内兵按**兵力降序**依次发起 ATTACK(兵, P)，每个进攻独立结算；一旦某兵进攻成功进占，后续进攻意图因目标地块变为友军而**自然失效**。
- **链后状态**：执行结束后**无上一个行为**，结束局面作为**根原点**进入基础行为段搜索。
- **提交**：最终提交的执行方案**必须包含前置链**（若成立）作为前缀。

## 4. 基础行为定义

### 4.1 铺场
| 项 | 内容 |
|---|---|
| 兵 | 我方**连兵**（有移动力）或**兵力 1 的断兵**（有移动力） |
| 目标 | 距离 1 的**空地块**（空平原或空据点，非全断） |
| 意图 | 单意图 `MOVE` |
| 链转移 | 连兵移动后仍有移动力 → **规则1**；兵力 1 断兵移动后失去移动力 → **规则2** |

### 4.2 就近进攻
| 项 | 内容 |
|---|---|
| 兵 | 我方**连兵**，有移动力 |
| 目标 | 周围（距离 1）位于**陆地地块**（平原/据点，非海洋）的敌兵，**连兵断兵均可** |
| 条件 | 进攻成功：进攻力 ≥ 防守兵兵力 |
| 意图 | 单意图 `ATTACK` |
| 链转移 | 成功进占且仍有移动力 → **规则1**；边界（进攻力 = 防守兵力，进占失败，原地留兵力 1 连兵）→ **规则2** |

### 4.3 远海进攻
| 项 | 内容 |
|---|---|
| 兵 | 我方**连兵或断兵**，有移动力 |
| 目标 | ①**海洋地块**上的敌兵；②**沿海平原**（与海洋相邻的平原）上的敌兵 |
| 条件 | 存在水路路线（含第一步"直接下海"：陆地 → 海洋，之后全海洋），兵到达目标周围（距离 1），且到达后进攻成功。**目标为沿海平原**：进攻力 ≥ 防守兵力（**含同归于尽**，无进占也算远海进攻）；**目标为海洋**：进攻力 **>** 防守兵力（严格大于——等于时归兑换，不视为远海进攻） |
| 意图串 | `[MOVE 序列（水路）] → [ATTACK]` |
| 链转移 | 进占后：目标为海洋 → 断兵失去移动力；目标为沿海平原 → 从海洋进占触发进入失活；若重连为连兵（连友军网络）则仍有移动力 → **规则1**，否则 → **规则2** |

### 4.4 自杀
| 项 | 内容 |
|---|---|
| 兵 | 我方兵 A（连兵或断兵），有移动力；目标敌兵 X |
| 条件 | ① A 能以就近或远海方式对 X 发起进攻，且该进攻**必然失败**（A 到达 X 周围后进攻力 < X 兵力）；② 存在其他我方兵 B 能对 X 发起合法进攻（不论成败），且所有此类 B 到达 X 周围时的兵力（含各自移动损耗：连兵下海连→断 −1、断兵每步移动 −1）均 **> A 到达时的兵力**；③ **新增（2026-09-20）**：A 是**海洋断兵**，且发起必败进攻后出现**新的**可以进行**远海进攻/自杀**的我方兵（进攻前不能、进攻后能——X 被削弱或航道打通）→ 允许 A 发起自杀（海洋版"消耗战开瓶器"） |
| 意图串 | `[A 的移动（至 X 周围）] → [ATTACK(A, X)]`（必然失败） |
| 链转移 | A 死亡（X 有反击）或失去移动力（X 无反击）→ **规则2-自杀分支**（消耗战循环，见 §5.2b） |

### 4.5 兑换
| 项 | 内容 |
|---|---|
| 兵 | 我方兵 A（连兵或断兵），有移动力；目标 X 位于**海洋地块** |
| 条件 | ① A 沿**最短**水路路线到达 X 周围后进攻成功（到达后进攻力 ≥ X 兵力）；② 存在水路路线 R（**最短或绕路均可**，最短即满足也算兑换）使 A 到达 X 周围时兵力**恰好等于** X 兵力——进攻成功且反击伤害 = X 兵力，A 兵力归零 → **同归于尽、无进占**；该情形**不视为远海进攻** |
| 绕路机制 | 海洋上断兵每移动一步兵力 −1（复制 −1）；连兵下海连→断兵力 −1。在海洋格间往返即可白白消耗兵力 |
| 意图串 | `[A 的绕路移动序列] → [ATTACK(A, X)]`（同归于尽） |
| 链转移 | A 与 X 均死亡 → **规则2-兑换分支** |

## 5. 链推进规则

### 5.1 规则1（锁兵延续）
上一个行为结束后，若该行为产生了**仍有移动力的兵**（移动行为的生成兵 / 进攻成功进占后的兵），则下一个行为**必须由该兵执行**，且只能从该兵的 **5 种基础行为**中选择（前置与防守不参与）。若该兵无可执行的基础行为 → 链终止，剪枝 E_ape。

### 5.2 规则2（链终止）
上一个行为结束后，若被操作兵**无法继续行动**（满足任一）：
- 兵死亡（被反击删除 / 同归于尽）；
- 兵失去移动力（进入失活 / 接触失活 / 断兵进攻后 / 兵力 1 连兵 / 兵力 1 断兵移动后等，见战斗规则 §4.3）；
- 行为未产生可操作的新兵（如连兵进攻力 = 防守兵力时进占失败）。

则按上一行为类型分派：

**a) 铺场 / 就近进攻 / 远海进攻**：链终止。对终止局面计算**剪枝 E_ape**，作为该链在其起点原点处的打分。

**b) 自杀 —— 消耗战循环**：
1. A 进攻 X 失败（A 死亡或失去移动力）后，维护**补刀列表** L = { B | B 未使用，且存在仅由铺场/就近进攻构成的合法序列使 B 到达 X 周围、全程保持可行动，到达后能对 X 发起合法进攻 }（**不要求进攻成功**）。
2. L 为空 → 链终止，剪枝 E_ape。
3. 从 L 选 B：B 在进攻 X **之前**只能从铺场/就近进攻中选择行为（受规则1 锁定时亦然）；随后 B 进攻 X：
   - **X 被成功攻击**（X 死）→ 解除 B 的行为类型限制；B 若仍有移动力 → 规则1 锁 B 继续 → 最终回规则2 终止，剪枝 E_ape。
   - **B 进攻失败** → B 死亡或失去移动力，移出 L；回到步骤 2。

**c) 兑换**：不立即终止。下一个操作（**仅紧邻一次**）只能是**兑换 / 远海进攻 / 自杀**，行动兵可为任意满足条件的兵（不限于上一兵）。所选行为完成后，按其自身类型回 a/b/c 分派。

## 6. 基础行为段搜索算法

```
输入：行动阶段开始局面 S0
① 前置判定：行动阶段开始时判定进攻据点条件
      ├─ 满足 → 执行前置链 → 根原点 = 前置链结束局面
      └─ 不满足 → 根原点 = S0
② 基础行为搜索：
    函数 search(O, 路径 P):
        if O 无任何合法基础行为（5 种均不可执行）:          # 叶子
            得分 = E_ape(O)                                # 方案得分（基础行为段）
            记录方案(P, 得分); return
        链集合 = 从 O 枚举所有合法基础行为，各按规则1/2推进至终止
        # 剪枝优化（v1.4）：若 O 存在自杀行为或兑换行为（任一成立），
        # 则剪除铺场/就近进攻/远海进攻分支，链集合仅保留自杀/兑换行为分支；
        # 即条件允许时，行为链必须从自杀/兑换开始。
        # 该剪枝仅作用于原点枚举；规则1 锁兵状态下的行为选择不应用
        每条链分数 = 链终止时的剪枝 E_ape（自杀/兑换分支的链在最终终止时整体打分）
        取分数最高的 4 条链 L1, L2, L3, L4                      # top-4
        for L in {L1, L2}:
            search(L 实施后的终止局面, P + L)

    search(根原点, [前置链(若成立)])
③ 汇总所有方案得分，取最高的 6 条作为候选执行方案，全部提交（训练环境 top-6）
④ 防守行为段：对 3 条候选路径分别执行 §2.1 防守流程，
   每条路径得到整体行动方案（前置链 + 基础行为意图 + 防守意图列表）
```

**终止性**：无需深度限制（P3）。原点无 5 种基础行为可执行即成为叶子；每条行为链因消耗移动力/兵力/地块而必然终止；棋盘资源有限保证搜索在有限步内到达全部叶子。
