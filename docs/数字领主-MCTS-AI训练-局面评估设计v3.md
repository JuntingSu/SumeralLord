## 1. 设计目标与战术机制基础

新评估围绕五个实战战术设计。AI 通过"评估奖励可吃/可断电状态 + rollout 正确演算"自发学会这些战术，而非硬编码动作序列。

| # | 战术 | 规则机制 | 评估中的体现 |
|---|---|---|---|
| T1 | 骗点 | §8.1.2：进攻失败自杀消耗敌反击（counter −1）→ 后续大兵免伤吃兵 | γ（交换潜力）+ LR 判据 |
| T2 | 下海机动 | §8.1.1 + §3.1：2 兵力连兵移动入海 → 半断强制变 1 断兵且保留移动力 → 威胁 2 格外目标 | 可达性（下海 2 格） |
| T3 | 速胜 | §5：连兵数 = 每回合点数收入；优势方持续交换滚雪球 | β（经济）+ LR 阈值动态化 |
| T4 | 断电 | §8.4.1：连→断 **兵力 −1**；吃连接兵连锁断连 | δ（断电潜力，割分析） |
| T5 | 铺场 | §8.1.1：连兵移动"复制兵力−1、目标留 1"，不耗移动力可连续走 → 沿途留链、连兵数↑ | β（边缘连兵）+ 加点器 |

**防守统一原则 [定稿]**：防守 = 让对手的进攻 LR 不划算（点数加厚路径 / 海洋路障部署 / 终局防护），由"加点器预算1（点数手段）+ 行动阶段防守类行动（兵力手段）"两套互补执行，不单独设计"防守评估"。

### 1.1 评估必须遵守的规则事实 [定稿]

1. 连兵进攻力 = 兵力 − 1，断兵 = 兵力（§4.2）；只有连兵可加点。
2. 据点驻军反击次数 ∞（§3.1）→ 不可免伤吃；平原/海洋兵反击次数 1。**主战场在非据点地块，据点仅作为计算边界条件，不做主特征。**
3. 进攻成功：防守兵按**被删前原始兵力**反击（§8.1.2 步骤 1）；同归于尽时防守兵仍被删除（步骤 2 无条件执行）。
4. 进攻失败且防守兵**无**反击：进攻兵保留、仅失去移动力（§8.1.2 情形 2）→ "免费咬"：无反击目标是公共沙包，多个小兵各咬一口均不消失。海战长期消耗由此而来。
5. 连兵移动不消耗移动力、可连续走（§8.1.1），每步"复制兵力−1 到目标、原地留 1"；断兵移动删除原兵、目标复制兵力−1，**每格损耗 1 兵力**、不留资产。
6. 断兵进攻成功后仍是断兵 → 失去移动力（§4.2 表）→ 海洋路障战术：从海洋进攻的敌人必为断兵，吃掉路障断兵后停驻原地失活，堵死后续部队。
7. 点数发放 = 连兵数（§5）；连兵数减少 → 下回合点数减少（逐回合分析时加点损失只计一回合）。
8. 据点数归 0 → 势力清除（§8.4.2）→ 胜利。终局 = 吃敌方最后一个据点兵。

### 1.2 回合时序与点数规则 [定稿]（v3 新增，R1）

回合固定流程（规则 §6.1）：**准备 → 行动 → 加点 → 结束**。

- **行动阶段**：只能对现有局势操作（移动 / 进攻 / 防守部署）。**不产生任何点数变化——回合内行动阶段没有加点**。
- **加点阶段**：使用本回合发放的点数（= 连兵数），**仅为下回合准备**——加厚路径、升 Q、备弹药、铺场，全部作用于**下回合**的行动阶段。
- 回合内行动与加点**互斥**：行动阶段无加点，加点阶段无行动。
- **敌我对称**：敌方行动阶段可用的兵力 = 其此前各回合加点累积的现有兵力；预测对手行动（§5 近似层）用其现有兵力。
- **推论（贯穿全文）**：一切"为执行行动而加点"的表述均指**此前回合**的投入；LR 等行动判据中不存在"本回合加点花销"项，兵力消耗即点数损失（兵力数值 = 基础兵力 + 历史加点累积）。

## 2. 叶评估 E [定稿]

rollout 满 H 回合未终局时，对截断状态从**当前行动玩家视角**计算：

```
E = α·R' + β·N' + γ·T' + δ·D'

S    = Σ我兵力 + Σ敌兵力                        （总兵力，ε=1 防零）
R'   = (Σ我兵力 − Σ敌兵力) / S                   → 兵力比例差 [−1,1]
N'   = (c_我 − c_敌) / max(c_我, c_敌, ε)
     + ρ·(e_我 − e_敌) / max(e_我, e_敌, ε)
     − σ·(d_我 − d_敌) / max(d_我, d_敌, ε)      → 每回合点数比例差 + 铺场潜力 − 死兵浪费
T'   = (TP我 − TP敌) / S                          → 可兑换资源占比（交换潜力）
D'   = (DP我 − DP敌) / S                          → 断电潜力占比
```

- **c** = 连兵数（§5 点数收入）。**e** = 边缘连兵数，**d** = 死兵数（定义见 §4.5）。
- **TP / DP** 由行动解析器执行模拟得出（§4.4），非直接求和；分工约定：**cut(x) ≤ 1 的敌兵归 γ（单点吃兵），cut(x) > 1 的归 δ（断电行动，分子含连锁）**，互不重叠、无双重计算。
- 归一化目的：四项同量纲 O(1)，权重 α β γ δ 为纯相对重要度，跨地图尺寸可移植；E 量级约 [−3, 3]，终端 ±5 仍主导搜索。

### 2.1 权重表 [定稿]

| 权重 | 语义 | 初值 | 调参区间 |
|---|---|---|---|
| α | 兵力比例差（资源底线，防打光家底） | 0.4 | [0, 2] |
| β | 经济比例差（滚雪球燃料） | 0.6 | [0, 2] |
| γ | 交换潜力（主战术） | 1.0 | [0, 2] |
| δ | 断电潜力 | 0.8 | [0, 2] |
| ρ | 边缘连兵子权重（β 内，铺场潜力） | 0.3 | [0, 1] |
| σ | 死兵惩罚子权重（β 内，加点浪费） | 0.2 | [0, 1] |
| w_d | 单位断连价值（§4.3） | 2 | [1, 4] |
| θ₀ | LR 阈值基准（§3.2） | 1.5 | [1.2, 2.0] |
| k | 阈值动态化斜率（§3.2） | 0.2 | [0, 0.5] |

## 3. 行动判据 LR [定稿]

LR 是 rollout 内**交换类行动**（骗点/吃兵/断电/免费咬）的统一决策尺子：算清一次行动的真金白银得失再动手。防守类与投资类行动不走 LR（分子 = 0 永远不过阈值），分别见 §4.1 与 §5。

### 3.1 公式

```
LR = 敌损失 / 我损失 > θ

敌损失 = 被吃兵兵力
       + 敌连兵减少数 × 1          （下回合加点流失，逐回合只计一回合）
       + 断电行动时 (cut(x)−1)·w_d  （连锁断连部分）

我损失 = 我消耗兵力                （弹药兵力 + 攻击兵净损耗 + 位移损耗 + 网络放弃，见 §4.2）
       + 我连兵减少数 × 1

注 [定稿，R1]：行动阶段不产生任何点数消耗（§1.2）。消耗的兵力即"现有点数存量"
（基础兵力 + 此前各回合加点累积）的直接损失；"升Q/准备骗点"的加点投入已包含在
兵力数值中，不重复计列。诱导花销不记。
```

### 3.2 阈值动态化 [定稿]

```
θ = θ₀ + k·min(0, (敌总兵力 − 我总兵力) / max(我总兵力, ε))
```

- 我优势（敌 < 我）：θ 低于 θ₀，优势越大阈值越低 → LR>1.0 左右的持续交换开始执行 → 速胜节奏（T3）。
- 我劣势（敌 > 我）：θ 保持 θ₀，不额外加码（保守：劣势侧由 α·R' 底线引力兜着）。

### 3.3 终局行动特例 [定稿]

```
终局行动：攻击 x，x 所在地块为据点（terrain=1），且删除 x 后敌方据点数 = 0
  → 必执行：跳过 LR 阈值比较，rollout 最高优先级
  → 前提：存在可达攻击兵且进攻力 ≥ 兵力(x)
    （进攻成功或同归于尽均有效——§8.1.2 步骤 2 无条件删除防守兵，
      同归于尽同样触发据点 −1 → 清除）
```

终局引导完全交给该特例 + 终端值；**叶评估不加据点数特征**（延续"不过分注重据点"取向）。

## 4. 行动解析器（评估与 rollout 共用）[定稿]

统一实现"可达性 + 攻击成本 + 资源约束"，评估侧算潜力与 rollout 侧执行使用同一口径（保证评估 LR 与执行 LR 同源）。

### 4.1 候选行动生成（三类行动）

```
【行动解析器】输入：状态 + 视角玩家 → 输出：候选行动列表

── 交换类行动（LR 判据，§3）──
组合行动 = (可选弹药 a′ + 攻击兵 a + 目标 t)
  终局行动：t 为据点兵且删除后敌据点归 0（§3.3）→ 必执行，无 LR 限制
  断电行动：cut(t) > 1        → 分子 = 兵力(t) + (cut(t)−1)·w_d
  吃兵行动：cut(t) ≤ 1        → 分子 = 兵力(t)
  免费咬  ：t 当前无反击次数   → 攻击兵任意可达小兵，我损失 ≈ 0
  每个行动：LR = 分子 / 我损失(t)；净收益 = 分子 − 我损失(t)
  可执行条件：LR > θ（终局行动除外）

── 防守类行动（威胁现值判据，v3 新增，R2）──
(防守兵 b, 目标格 g, 威胁 T)
  威胁源：解析器(对手视角, 对手当前状态) 输出 = 对手下回合可执行行动
          （终局 / 断电 / LR>θ 吃兵；含下海 2 格机动，即"1 回合威胁窗口"）
  防守收益 = T 的净收益（我不防守时对手下回合赚到的）
  防守成本 = b 的兵力损耗（部署后暴露） + 位移损耗
  可执行 iff 防守收益 > 防守成本 且 b 可达 g
  形态：
    海洋路障 [定稿]：1 断兵 b 部署到被保护节点 n 的海洋入口格 g
      ——从海洋进攻的敌人必为断兵，吃路障后失移动力停驻堵死后续（§1.1 事实 6）
    陆地路径堵位 [默认]：b 部署到对手必经路径瓶颈格 g（对手通过须先进攻 b）
      ——陆地堵位主要靠"对手吃 b 不划算"生效，其点数加厚版由加点器预算1 负责（§5）
  资源约束：b 消耗移动力；1 断兵部署后失去移动力，本回合不再行动

── 投资类行动（现值判据，§6 执行）──
铺场机动：边缘连兵移动留链（收益 = 连兵数+1 的贴现；判据 = 现值收益 > 暴露成本）
```

- 为什么铺场/防守不走 LR：LR 分子 = 敌损失，这两类不直接造成敌损失（防守收益是"避免未来损失"，铺场收益是"未来经济"），用各自的现值判据。
- "骗点 + 吃兵"作为一个组合行动过一次 LR（分母含弹药消耗 + 攻击兵损耗），不是两步各判一次。

### 4.2 我损失（攻击成本）明细

```
我损失(t) = 弹药消耗 + 攻击兵净损耗 + 位移损耗 + 网络放弃价值

弹药消耗：t 有反击 → 弹药 a′ 的兵力（任意兵均可做弹药，无固定清单）；
          t 无反击 → 0
攻击兵净损耗：受反击伤害（骗点成功则 0；未骗点 = 兵力(t)）
           + 进占损耗（连兵 1 / 断兵 0，§8.1.2 补充规则）
位移损耗：断兵化跨格每格 1 兵力（断兵移动删原兵复制−1，§8.1.1）
网络放弃价值：攻击兵 a 是连兵时，扣其网络价值（β 视角）；1 断兵/2 连兵等弹药不计

注 [定稿，R1]：无"加点摊销"独立项——兵力数值已含此前各回合加点投入（§1.2 推论）。
```

### 4.3 cut(x) 全量割分析 [定稿]

```
cut(x) = 删除敌兵 x 后，无法连通到任何全接地形（terrain=1）地块的敌方连兵数

实现：根集合 R = 全部 terrain=1 地块（多据点 = 多根，与占领者无关，§4.1 连兵性本质）；
      删除 x 后，从 R 中各地块 BFS 敌方连兵网络（仅走同势力连兵节点、邻接边），
      统计可达连兵节点集；cut(x) = 敌方总连兵数 − 可达数。
成本：O(V·(V+E))，每叶子一次；~100 格地图 ≈ 2 万操作，可接受。
```

### 4.4 评估侧执行模拟（TP/DP 计算）[定稿]

```
TP我 = 执行模拟后 吃兵/免费咬行动 净收益之和
DP我 = 执行模拟后 断电行动     净收益之和
（TP敌 / DP敌 对称：敌方视角解析器对己方结构的结果 = 己方暴露面）

执行模拟：解析器输出（交换类）→ 按净收益降序排序 → 依序执行并扣除资源（单遍贪心，不重算 LR）
资源约束：攻击兵一回合一次（移动力）；弹药 a′ 一次抵消一次反击；
          免费咬每兵一口；断兵位移逐格 −1
```

- 排序键 = 净收益（先做最赚的）；LR > θ 只是执行门槛。
- 单遍贪心为 [默认]：共享资源（同一弹药/同一攻击兵）被排序靠前的行动占用后，靠后的目标实际成本上升、净收益下降 → Σ 高估自动消除。rollout 侧执行时用"每执行一个重调解析器"的精确版（§6）。
- 执行模拟**只算可兑现值，不改状态**（β/δ 等其余特征仍用原状态计算）。
- 防守类行动不进入 TP/DP 执行模拟（它是防守侧，由 DP敌 的暴露面与 §5 防守预算体现）。

### 4.5 死兵 / 边缘连兵定义 [定稿]

```
死兵：连兵 p 的所有邻格 g 均满足：g 为全断地形（山地/虚空/越界）或 g 上有同队伍兵
      （即有同队伍兵 → 不可移动；无兵但可进入 → 可移动铺场，非死兵；
        有敌兵 → 可进攻，非死兵）
边缘连兵：存在邻格 g 为"可进入空地"（非全断地形且无兵）的连兵
      （可移动留链铺场；死兵的严格反面是"既不可移动也不可进攻"，边缘只要求可移动）
```

### 4.6 可达性精确规则 [定稿]

```
可达(t)（评估视角，1~2 回合窗口）：
  普通：存在我兵 a，dist(a,t) = 1（邻格，§2.3 邻接表），且 a 有移动力
        → 可进攻 / 可骗点 / 可免费咬
  下海 2 格：存在 2 兵力连兵 a 与海洋格 m：
        dist(a,m) = 1 且 dist(m,t) = 1（a 下海变 1 断兵保留移动力，再走/攻 1 格）
        → 远程弹药可达（骗点 / 免费咬 / 吃 1 兵力目标；攻击力 1）
路径约束：全断地形不可经过；海洋可进入（半断可站兵）
```

- 大断兵跨格（每格 −1 损耗）不计入"可达"快捷判定，其代价已由 §4.2 位移损耗覆盖，LR 判据会自然拒绝不划算的用法。
- 据点兵（反击 ∞）：不可免伤吃，不计入 TP 目标（仅终局特例可攻击）。

## 5. 加点器（rollout 内 ADD_POINT 阶段）[定稿]

加点 = 为**下回合**行动做准备（§1.2：回合内行动阶段无加点），只干两件事，按预算分配：

```
【预算1 防守】（优先，点数手段；行动手段见 §4.1 防守类行动）
  威胁源：解析器(对手视角, 对手当前状态) 输出 = 对手下回合可执行行动（LR > θ / 终局 / 断电）
  对手预测近似层 [默认]：用对手当前兵力计算，忽略其本回合加点提升（低估，
      避免过度防守浪费点数；后续可升级为"加点上限估计"）
  对每个威胁行动：计算"加厚路径/目标兵使对手 LR ≤ θ 所需最小点数"；
      防守花销取两种手段的较小者：
        点数版（预算1）：路径/目标兵加厚（本回合加点，下回合生效）
        行动版（§4.1 防守类）：海洋路障部署（ACTION 阶段用现有兵力，不花点数）
      按威胁净收益降序分配；预算不足时按优先级：
      终局威胁（§3.3 防守侧）> 断电威胁 > 大净收益吃兵威胁

【预算2 进攻准备】（剩余点数）
  按"下回合行动的边际 LR 提升"排序分配：
      升Q（兵升到足以吃目标 → 下回合 LR↑）
      弹药准备（保留/制造 1 断兵或 2 连兵弹药）
      边缘铺场（边缘连兵 +1 点 → 下回合移动留链 → 连兵数↑，T5）
  死兵边际 = 0（无路可走连兵不加点，§4.5）
```

## 6. rollout 完整流程 [定稿]

```
【rollout · 每回合，对当前行动玩家】
1. 准备阶段（引擎自动）：点数发放、移动力发放、反击刷新（§6.1 规则）
2. ACTION 阶段（解析器驱动；只能用现有兵力，无加点）：
   a. 解析器(我方视角) → 候选行动（交换类 + 防守类）
   b. 终局行动存在 → 执行，跳到步骤 3
   c. 防守类：威胁窗口 ≤ 1 回合（对手下回合可执行）且 防守收益 > 成本
      → 按威胁净收益降序执行（海洋路障部署优先于陆地堵位）
   d. 交换类：LR > θ 的行动按净收益降序逐个执行，
      每个执行后重调解析器（精确版：弹药消耗/移动力/断连变化被下一行动看见）
   e. 剩余移动力 → 投资类铺场机动（边缘连兵移动留链，
      判据 [默认]：现值收益 = 1 连兵 × β 权重 > 该兵暴露成本（被吃净收益））
3. ADD_POINT 阶段：加点器（§5，为下回合准备）
4. 结束回合（引擎自动）
```

H 回合未终局 → 叶评估 E（§2）；中途终局 → 终端值（旧方案 §3.2：R = 5·(outcome + (1−2p̂))，截断 −4.5，保持不变）。
